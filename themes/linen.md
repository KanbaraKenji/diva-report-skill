# 素纸 Linen（默认 · 浅色 · 克制商务）

对外发文的安全牌。中性纸白配靛蓝，不抢内容、打印好看、转发出去不会被说"花哨"。
靛蓝是刻意避开"暖米色 + 陶土橙"那套 AI 默认配色选的。

## 色板

| 变量 | 值 | 说明 |
|---|---|---|
| `--paper` | `#FCFCFB` | 极浅中性纸白，不带黄 |
| `--panel` | `#FFFFFF` | 面板纯白，靠一根线与纸面区分，不靠阴影 |
| `--ink` | `#1C1D1F` | 正文（对比 15.9:1） |
| `--ink-2` | `#5B6068` | 说明、表头 |
| `--ink-3` | `#8A9099` | 时间戳、单位 |
| `--line` | `#E3E5E8` | 分割线 |
| `--accent` | `#2F4B7C` | 靛蓝——结论、主数据、时间线当前位置 |
| `--ok` | `#2E7D5B` | 正常 |
| `--warn` | `#B7791F` | 注意 |
| `--bad` | `#B3261E` | 异常 |

## 字体

```css
--sans:"PingFang SC","Source Han Sans SC","Noto Sans SC","Microsoft YaHei",system-ui,sans-serif;
--mono:"IBM Plex Mono","SFMono-Regular",Consolas,"Liberation Mono",monospace;
```

标题 700 / 小标题 600 / 正文 400，一族到底，不换第二个字族。

## 用在哪

给主管的周报、评审结论、完工报告、对外正式函件的附件。**拿不准用哪套时就用这套。**
