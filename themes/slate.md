# 石板 Slate（深色 · 备用）

⚠️ **默认不要用。** 企业环境里深色报告转发出去常被判为"不正式"，打印还会糊成一片。
只在这两种场合用：内部值班大屏、用户明确要求深色。

打印时**必须**切回浅色——这套主题的打印样式直接覆盖成白底黑字，不要试图打印深色。

## 色板

| 变量 | 值 | 说明 |
|---|---|---|
| `--paper` | `#12151A` | 页面底 |
| `--panel` | `#1A1F27` | 面板 |
| `--ink` | `#E6E9EE` | 正文（对比 13.4:1） |
| `--ink-2` | `#9AA3B0` | 说明、表头 |
| `--ink-3` | `#6B7582` | 时间戳 |
| `--line` | `#2A3039` | 分割线 |
| `--accent` | `#4FA3C7` | 结论、主数据 |
| `--ok` | `#4FB286` | 正常 |
| `--warn` | `#D9A441` | 注意 |
| `--bad` | `#E06C6C` | 异常 |

深色下语义色要**提亮降饱和**，直接套浅色主题那三个值会发暗看不清。

## 字体

同 `linen.md`。

## 打印覆盖（必须写进 `@media print`）

```css
@media print{
  :root{--paper:#fff;--panel:#fff;--ink:#111;--ink-2:#555;--ink-3:#888;--line:#ddd;
        --accent:#1F4E6E;--ok:#2E7D5B;--warn:#96610F;--bad:#A81F1F}
}
```
