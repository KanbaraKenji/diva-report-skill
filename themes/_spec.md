# 主题怎么写

一个主题＝**一份色板 + 一组字体栈 + 一句"用在哪"**。不含布局，不含组件——换主题不该改结构。

必须给齐这 11 个变量，缺一个就会有人临时编一个颜色出来：

| 变量 | 作用 |
|---|---|
| `--paper` | 页面底色 |
| `--panel` | 浮起面板/卡片底色 |
| `--ink` | 正文（全强度，**永远不调灰**） |
| `--ink-2` | 说明、表头 |
| `--ink-3` | 时间戳、单位、最弱注记 |
| `--line` | 分割线、表格线 |
| `--accent` | 唯一强调色，只用于结论 / 主数据 / 当前位置 |
| `--ok` `--warn` `--bad` | 语义色，只表状态 |
| `--sans` `--mono` | 字体栈；`--mono` 只给数字用 |

自建主题时：
- 先定 `--paper` 和 `--ink`，把对比度拉到 ≥ 12:1，剩下的灰阶从这两端插值。
- `--accent` 要和三个语义色都能区分开——**强调色撞上"正常绿"是最常见的错**。
- 字体栈第一位写具体字体，最后一位一定要有 `system-ui` / `sans-serif` 兜底；不要引网络字体（见 HTML 契约第 2 条）。
- 写完对照 `references/visual-rules.md` 的反 AI 味清单第 1、2 条，别又调回那两套配色。
