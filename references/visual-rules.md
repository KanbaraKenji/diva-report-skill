# 视觉纪律

目标不是"好看"，是**读者三秒内抓到重点、转发出去不丢脸**。

## 一、一页只有一个主角

选定一处下重手（一个大数字、一条时间线、一张对比表），**其余全部压低**。
两个主角等于没有主角。舍不得压低其他块，就是这份报告还没想清楚重点。

## 二、层级靠字号、字重、留白，不靠灰度

**正文永远是全强度颜色。** 想表达"次要"，用小一号字、细一档字重、多一点留白——不要把正文调灰。
灰度只分三档，各有各的职责，不存在"再淡一点"的中间档：

| 角色 | 用在哪 |
|---|---|
| 内容 | 正文、标题、表格数据、列表项 |
| 说明 | 字段说明、图注、辅助信息 |
| 提示 | 时间戳、单位、最弱注记 |

## 三、强调色只有一种，且要省着用

一份报告一个强调色，只用在**结论、主数据、当前位置**这三处。
状态另有一套语义色（正常 / 注意 / 异常），语义色不算强调色，**也不要拿强调色去表状态**。
不用渐变做装饰。渐变只在它真的编码了信息时才用（比如热力密度）。

## 四、结构装置要编码信息，不要当装饰

边框、分割线、编号、序号、色块——**每一个都必须在告诉读者一件事**。

- 编号 01 / 02 / 03 只在内容**真的是一个顺序**时才用（流程步骤、时间线）。并列的三个选项不是顺序。
- 圆角不要全站一个值：卡片和按钮的圆角本来就该不一样，一刀切是模板感的来源。
- 阴影要么不用，要么只给真正浮起来的那一层用。每个块都挂同一个淡灰阴影＝没有层次。

## 五、数字优先于形容词

写"延期 6 天"，不写"有所延迟"。写"12 项中 9 项通过"，不写"大部分通过"。
形容词只在数字已经给出之后，用来定性。

## 六、动效

报告基本不需要动效。
`<details>` 展开这种**回应用户动作**的过渡可以留（120–200ms）。
**页面加载时逐块淡入、每张卡片 hover 抬起——这两样是 AI 生成页面最明显的标志，不要写。**

## 反「AI 味」清单

下面这些是当前 AI 生成页面**扎堆出现**的默认套路。它们本身不丑，问题在于不论什么内容都长一个样。
除非用户明确要求，**一律避开**：

1. **暖米色底 + 高对比衬线大标题 + 陶土橙强调色**（`#F4F1EA` 配 `#D97757` 一带）。这套配色出现频率最高。
2. **近黑底 + 一个荧光绿/朱红强调色**。
3. **报纸风**：发丝线、零圆角、密排多栏。
4. **SaaS 卡片套件**：内容全切成一样大小、一样圆角的卡片，每张挂同一个 `rgba(0,0,0,.1)` 淡灰阴影，再刷几块渐变当装饰。
5. **模板腔**（不论什么主题都出现的那几样）：
   - 每个标题上面顶一个拉开字距的 ALL-CAPS 小眉标
   - 元信息用中点串起来：`A · B · C`
   - `WORD — 半句话` 这种"词 + 空格破折号"的标签
   - 拿 `#0B0B0B` / `#111` 这类偏黑替代纯黑
   - 小标签一律上等宽字体
   - 链接和按钮文字后面缀一个 `→`
   - 标题里把某一个词挑出来变色或加粗

⚠️ **等宽字体有一个正当用法**：数字表格里靠等宽对齐小数点。这是功能，不是装饰——**只给数字用，不要给标签用**。

## 交付前自查清单

写完 HTML 后逐条过，**有一条不过就回去改**：

- [ ] 读者不滚动就能看到结论？
- [ ] 这一页的主角是谁，一句话说得出来？
- [ ] 强调色是不是只有一种，是不是只出现在结论和主数据上？
- [ ] 有没有把正文调灰来"分层级"？
- [ ] 编号 / 边框 / 色块，每一样都在告诉读者一件事吗？有纯装饰的删掉。
- [ ] 有没有页面加载淡入、卡片 hover 抬起？有就删。
- [ ] 对照上面七条模板腔逐条看一遍，中了吗？
- [ ] 形容词能换成数字的都换了吗？
- [ ] Ctrl+P 预览过吗？表格有没有被切成两半？背景色还在吗？
- [ ] 断网打开还完整吗？（没有任何外链）
- [ ] 窗口拉到手机宽度，横向滚动条出现了吗？（表格除外）
