# 执行 skill 时暴露的问题（供优化用）

来源：四个 Agent 各自独立按 skill 写一份 HTML 报告时记录的「不清楚 / 矛盾 / 缺指引 / 只能猜」，
加上把骨架搬到 PPT 时的观察。已去重、合并，按「改一处能解决多少问题」排序。
每条后面括号里是哪几份示例撞上了它。

## 一、文件之间互相矛盾（优先修，Agent 会在两份文件之间二选一）

1. **`--ink` 全是偏黑，但反 AI 味清单第 5 条禁止「用 #0B0B0B / #111 替代纯黑」。**
   四套主题的 `--ink` 分别是 `#1C1D1F` / `#14181F` / `#111111` / 打印覆盖 `#111`。按主题抄就必然「中招」。
   建议：清单改成「不要在主题色板之外另配偏黑」，或主题改值。（1/2/3/4）
2. **`examples/specimen.html` 自己违反清单。** 页脚 `单文件 · 零外链 · A4 可打印`、`h2 .n` 的计数都是中点串元信息（清单第 5 条）。
   四个 Agent 都是先照抄样张，自查时才发现要改。建议样张改掉，并在清单里说明「标题里的中点可以，元信息行不可以」。（1/2/3/4）
3. **specimen 的 SVG 颜色写死十六进制，html-contract 却要求「颜色一律走 var(--accent)」。**
   照抄样张就违反契约；换主题或打印时颜色不会跟着变。建议样张改成变量。（1/3/4）
4. **强调色用途三处说法不一。** visual-rules：只用于「结论 / 主数据 / 当前位置」；specimen：结论里的问题用 `--bad` 点出，强调色只在主角格边框和时间线；blueprint.md：`--accent` 用于「实测值」整列。
   审查报告按 blueprint 做会让表格整列发蓝，与「省着用」冲突。建议：统一成一句话，并明确 blueprint 的实测值列算不算例外。（1/2）
5. **press 主题 `--bad` 与 `--accent` 同值，撞上「不要拿强调色去表状态」。**
   对比报告里 C 的退货率 3.6% 本该标异常，一标就和推荐列混成一片。建议 press.md 说明这套主题下状态色怎么用，或注明对比/审查类报告别选 press。（3）
6. **页眉带「四项缺一不可」，骨架和样张却有第五项「范围」。** 建议写成「四项必有，范围可选」。（1/2/3/4）
7. **html-contract 骨架与 specimen 类名、打印写法对不上。** 契约的 `.card` 在样张里叫 `.cell`；`details` 打印三行两处写法略不同；样张多了 `.r`、`details:last-of-type`。新手不知道以哪份为准。建议以一份为准，另一份只引用。（2/4）
8. **slate.md 字体一栏写「同 linen.md」**，而 `_spec.md` 要求每套主题给齐 11 个变量。（4）
9. **`--mono` 栈首选 IBM Plex Mono 不是系统字体**，与契约第 5 条「只用系统字体栈」出入。另外 Linux 上回退到的 Liberation Mono 是斜杠零，看板里「0 天」显示成「Ø 天」。（1）

## 二、规则只在样张注释里，没进规则文件

10. **「结论里真正的问题用语义色点一处」**只出现在 specimen 的注记里，visual-rules 没写；而清单第 5 条又禁「标题里挑一个词变色」。一句话结论算不算标题？四个 Agent 都按「不算」处理，但都是猜的。建议收进 visual-rules 并划清边界。（1/2/3/4）
11. **「三档到顶，不要第四档」**（状态标签）只在样张里。审查报告的「不适用」、严重度的「轻微」都没有对应色，Agent 只能自造一个中性描边标签——算不算第四档没法判断。建议规范一个「中性 / 不适用」标签写法。（2）

## 三、骨架缺细节（report-types.md）

12. **审查报告的主角「总评数字」长什么样没有积木。** Agent 自己拼了三格「通过 / 不通过 / 不适用」，又担心这是「SaaS 卡片套件」。建议 specimen 加一个计数条积木。（2）
13. **审查报告的「不适用」项与「发现」「建议动作」的关系没说。** 建议补一句「不适用项要在建议动作里交代何时补做」。（2）
14. **对比报告「推荐列怎么标」没有做法**，且「每一维分高下」在表里怎么呈现（加粗？着色？推荐列允许有非最优格吗？）没说。另外每维的优劣方向（起订量越小越好？）需要领域判断，简报不给就只能猜。建议要求输入带方向，或报告里注明。（3）
15. **受阻报告「主角放最显眼处」与骨架顺序（卡点 → 根因 → 需要谁做什么）矛盾**，没说能不能把表提到页眉正下方。同时「已停工 6 天」天然想做大数字，又会和主角表抢戏。建议明说二选一，并说清卡点块怎么写才不抢戏。（4）
16. **进度报告的「异常明细」「本期变化」没有骨架**：字段用表、列表还是卡片，哪些露在折叠外，「原因长」的阈值，「无变化」项占不占行，都是猜的。（1）
17. **看板格数与响应式断点没给**：样张 3 格，4 格时 720px 以下怎么塌、打印时保持横排还是折行，没说。（1）
18. **看板大数字的上色规则看不出来**：样张里「+9 正常」是绿、「+2 注意」是黑。数字颜色跟状态还是跟数值？偏差 0 怎么上色？（1）
19. **时间线缺规范**：改期后的新节点怎么画（线型、颜色、浅灰段延不延到新节点），刻度密度、每天像素、标注避让，手机宽度下 SVG 算不算「宽表格除外」。（1）
20. **半空矩阵怎么办**：影响面是「两套方案 × 三个对象」，有一格简报没给值。「用户没提供的不要补全」之下是写「未提供」还是退回列表？（4）
21. **大屏场景没有布局指引**：slate 被定位为「内部值班大屏」，但骨架是 960px / 15px，挂墙上太小。（4）

## 四、边界不清（SKILL.md / visual-rules.md）

22. **「用户没提供的东西不要补全」针对事实，但说明性文字能不能加？** 图例、表注、「大数字为计划偏差（天），负数＝延期」这类文字，四个 Agent 都加了，都不确定算不算违规。建议明确「字段说明 / 图例可以加，事实不能加」。（1/2/3）
23. **「用用户的叫法」与反 AI 味清单冲突时谁优先？** 用户给的标题「周报 · 第 37 周」本身带中点。（1）
24. **等宽字体的边界**：日期、时间戳、百分比、「09-16 启动」这种混合单元格算不算「数字」？散文里的日期要不要等宽？一列里混有中文短句时整列右对齐看起来怪。建议给一条「数值列混文字怎么处理」。（1/2/4）
25. **「说明」级灰（`--ink-2`）的用法只列了「说明、表头」**，定义列表的标签（现象 / 根因）算不算？（4）
26. **`--ink-3` 的对比度低于契约 4.5:1**（linen 约 3.1:1，slate 约 3.9:1），契约没说「提示」级是否豁免。（4）
27. **「生成时间」「数据截止」从哪取值没说**：取墙钟还是用户给的；「数据截止」能不能附带口径说明（简报里带了括号，页眉一行就变得很长）。（3/4）
28. **press.md 既说「主题不含布局」又给布局指令**（行高、栏宽、单栏、留白更多），但正文字号、`.wrap` 宽度、h2 字号、节间距都没给，全靠猜。骨架也没有「h1 衬线 + 正文无衬线」的对应 CSS。（3）
29. **主题缺「非主角数据色」**：条形图里非推荐的柱子用什么色？11 个变量里没有。Agent 用了 `--ink-3`。建议 `_spec.md` 加一个 `--muted-data`，或 SVG 要点里写明。（3）
30. **容器里没有 CJK 衬线字体时 press 会退化成全无衬线**，与「两族必须明显不同，否则不如只用一族」冲突。用户机器上也可能出现。建议 press.md 提醒。（3）

## 五、交付前清单可以补的条目

31. **「Ctrl+P 预览过吗」在无头环境做不了。** 四个 Agent 都改用 Playwright `emulateMedia({media:'print'})` 或 `page.pdf()`。建议清单附一条无 GUI 的验证做法。（1/2/3/4）
32. 清单没有、但 Agent 自检时真抓到的问题：语义色是否被当强调色用；等宽是否误套到中文；图表数值是否溢出 viewBox；标题是否与它的表格 / 图分到两页。（1/3）
33. **骨架里的 `<details>` 打印三行是无条件带上的**，没用折叠块时可不可以删没说。（2/4）
34. **简报没说明 Playwright 需要 `PLAYWRIGHT_BROWSERS_PATH`**——这是本次环境的问题，不是 skill 的，记在这里只为复现。

## 六、搬到 PPT 时的观察（如果打算让 skill 也管幻灯片）

- 骨架和纪律基本能原样搬：一页一个块、一个主角、一种强调色、三档语义色、表格只画横线、数值直接标在柱上，在幻灯片上同样成立。
- 需要补的：每类报告「一页放哪块」的分页建议；幻灯片没有 `<details>`，「原因长就折叠」要换成「放备注或附页」；
  页眉带四项在封面怎么排；表格超过 12 行怎么分页；深色主题投影时的对比度要求。
- 字体栈要单独给一份 Office 可命中的（Microsoft YaHei / SimSun / Consolas），网页的系统字体栈写法在 .pptx 里没用。
